# Predbat Energy Studio

A modern, **read-only** Predbat dashboard for Home Assistant. Same look and feel as EMHASS Energy Studio; independently installable as its own Home Assistant app/add-on.

This initial version lives alongside EMHASS Energy Studio in the same custom App Store repository:

`https://github.com/hbvdh/emhass-energy-studio`

It reads Predbat's existing output entities and does not modify Predbat settings or inverter commands. See `predbat_energy_studio/DOCS.md` for setup, supported entities, and known limitations.

Version: **0.1.0**
